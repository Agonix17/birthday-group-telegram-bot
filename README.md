# Birthday Telegram Bot

MVP-бот на Python, который каждый день отправляет в Telegram сводку о днях рождения из Google Sheets.

## Возможности

- автоматическая отправка поздравления только при наличии именинника в текущую дату;
- сегодняшние дни рождения с возрастом, который исполняется;
- ближайшие 5 дней рождения с датой и количеством дней до события;
- отправка в группу, супергруппу, канал или конкретную тему форума;
- команды `/today`, `/birthdays`, `/birthday`, `/todaybirthday`, `/next`, `/nextbirthday`, `/test`, `/setup`, `/where`;
- чтение таблицы без хранения персональных данных на сервере;
- корректная обработка 29 февраля в невисокосный год.

## Формат Google Sheets

В первой строке должны быть заголовки:

| name | name+ | birth_date | active |
|---|---|---|---|
| Влад Агафонов | Влада Агафонова | 15.10.2008 | TRUE |
| Иван Иванов | Ивана Иванова | 02.10.1988 | TRUE |

`name+` — форма имени для поздравления. В списках используется `name`, а в автоматическом поздравлении — `name+`. Если `name+` пустой, используется `name`. `birth_date` принимается в формате `ДД.ММ.ГГГГ`, `ГГГГ-ММ-ДД` или как дата Google Sheets. `active` необязателен: пустое значение и `TRUE` означают активную запись, `FALSE` отключает человека.

## Локальный запуск

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите `BOT_TOKEN`.
2. В Google Cloud создайте Service Account, включите Google Sheets API и скачайте JSON-ключ.
3. Откройте таблицу доступом на email service account (поле `client_email` в JSON) с правом Viewer.
4. Скопируйте `.env.example` в `.env`, заполните переменные и положите JSON-ключ рядом с `bot.py`.
5. Установите Python 3.11+ и зависимости:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python bot.py
```

После команды `python bot.py` процесс должен оставаться запущенным, а в окне появится лог polling. Пока это окно открыто, бот принимает команды и выполняет расписание. Для остановки нажмите `Ctrl+C`. После изменения кода или `.env` снова выполните `python bot.py` — это и есть перезапуск.

Если Windows сообщает, что команда `python` не найдена, установите Python 3.11 или новее с сайта python.org и во время установки включите опцию `Add Python to PATH`.

### Первая проверка команд

1. Откройте личный чат с ботом в Telegram и нажмите `Start`.
2. Отправьте `/today` — бот должен прочитать таблицу и ответить полной сводкой.
3. Отправьте `/next` — бот ответит ближайшим днём рождения.
4. Если личные команды работают, добавьте бота в группу.
5. Для публикации в группе отправьте `/setup` обычным сообщением в общем чате. Для форума откройте нужную тему и отправьте `/setup` внутри неё.
6. Для проверки публикации используйте `/test` в группе.

Команды в личном чате и группе обрабатываются только пока запущен `python bot.py`. Канал используется как место публикации: для него надёжнее задавать `TARGET_CHAT_ID` в `.env`, а команды `/today` и `/next` проверять в личном чате с ботом или в группе.

### Настройка чата

Самый простой вариант — прописать `TARGET_CHAT_ID`. Для темы форума дополнительно укажите `MESSAGE_THREAD_ID`.

Либо добавьте бота в нужную группу и выполните в нужной теме команду `/setup`. Бот запомнит чат и тему в `delivery.json`. Для группы команда доступна администраторам или пользователям из `ADMIN_USER_IDS`.

В канале бот должен быть администратором с правом публикации сообщений; команды настройки для канала удобнее задавать через `.env`.

Команда `/test` отправляет полную сводку немедленно в настроенный чат. Команды `/today` и `/birthdays` показывают полную сводку в текущем чате. Команды `/birthday` и `/todaybirthday` вручную показывают поздравление только сегодняшних именинников. Команды `/next` и `/nextbirthday` без автоматической отправки показывают ближайший день рождения в текущем чате.

Автоматическая проверка по умолчанию выполняется в 00:00 (`SEND_HOUR=0`, `SEND_MINUTE=0`). Если в этот день именинников нет, бот ничего не отправляет. Если именинники есть, бот отправляет поздравление с именами, текущей датой и возрастом.

## Docker / VPS / Railway / Koyeb

```bash
docker build -t birthday-bot .
docker run --env-file .env -v "$PWD/data:/app/data" birthday-bot
```

Для любого VPS достаточно Docker или `python bot.py` под systemd. Для облачного деплоя важно использовать worker/service, который не засыпает, и сохранить `data/delivery.json` как persistent volume, если используется `/setup`.

### Деплой Python-версии через GitHub-сервис

Подключите этот репозиторий и выберите тип `Worker`/`Background service`, если сервис предлагает такой вариант.

Команда установки:

```text
pip install -r requirements.txt
```

Команда запуска:

```text
python bot.py
```

Добавьте переменные из `.env`, но для Google-ключа используйте переменную `GOOGLE_CREDENTIALS_JSON`: вставьте в неё целиком содержимое файла сервисного аккаунта. `GOOGLE_CREDENTIALS_FILE` на сервере не нужен.

Домен покупать не требуется: Python-бот сам подключается к Telegram через polling.

## Что понадобится от заказчика

- токен Telegram-бота;
- ссылка на Google Sheet;
- JSON-ключ Google Service Account (не публиковать в GitHub и чатах);
- часовой пояс и время отправки;
- ID чата или возможность выполнить `/setup` в нужной теме;
- при необходимости — Telegram ID администраторов.

В текущем MVP картинка не добавляется: текстовая сводка надёжнее и не требует отдельного хранилища изображений. Позже можно добавить общий баннер или персональные фото отдельным столбцом.
